# Sidebar

## Objetivo

Permitir navegação rápida entre as áreas do sistema.

---

## Localização

Sempre esquerda.

Nunca direita.

Nunca superior.

Nunca inferior.

---

## Estados

- Expandida
- Recolhida

---

## Largura

Expandida:

```text
240dp
```

Recolhida:

```text
72dp
```

```text

```

```

```

## Regras

Nunca alterar largura.

Nunca alterar posição.

Nunca alterar comportamento.

Sempre utilizar exatamente o comportamento do Web Player.
