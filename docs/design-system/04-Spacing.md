# Escala Oficial

Nunca utilizar medidas aleatórias.

Utilizar somente:

```text
4
8
12
16
24
32
40
48
64
96
```

## Padding padrão

```text
24
```

## Cards


```text

48
```

# Regras

Não usar espaçamentos improvisados.

Não alterar espaçamentos para "parecer melhor" sem comparar com o Web Player.

Toda exceção deve ser documentada.
