# IZ Play App v1.1

Esta pasta separa o app/player desktop do painel de gerenciamento.

Conteudo atual:

- `main.js`: processo principal Electron do app antigo.
- `index.html`: interface do player IPTV.
- `iptv-proxy.exe`: proxy local usado pelo app.
- `mpv.exe`: player externo.
- `ffmpeg-master-latest-win64-gpl-shared/`: runtime FFmpeg.

Para iniciar:

```powershell
cd C:\Users\deivi\Desktop\iz-play-app-v1.1
npm start
```
